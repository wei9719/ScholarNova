# 1.2.11 检索相关性、摘要筛选与相似论文

日期：2026-10-07。范围：搜索结果与论文详情；不调整用户的模型配置，不连接 Zotero，不改动本地模型项目。

## 为什么会出现“交通流修复”推荐钢结构

旧规则在处理中英混合查询时可能只留下 `data`，丢掉交通流和修复任务；旧相关度又允许通用词或子串命中获得很高的分数。展示顺序还混入了引用、质量等综合因素，用户看到的“相关度排序”并非严格按相关度排列。

本版保留未知中文专业词，以长词优先的内置映射处理已知术语；统一中英文研究词并区分领域与任务，通用词不再替代领域证据。交通流预测可以作为交通流修复的近邻，但不会仅凭“交通流”就视为完全相同的任务。相关度和综合推荐现在是两种排序，界面改为“匹配分 /100”，不是模型置信概率。

## 新功能如何使用

1. 搜索“交通流数据修复”，查看顶部几篇的研究主题，再切换相关度、综合推荐、年份、引用排序。
2. 在列表上方点击“有摘要”，只显示本次结果中确实包含摘要文本的论文；“暂无摘要”方便集中处理需要补全文的条目。筛选不重新调用搜索，新搜索会复位。
3. 打开一篇论文，进入“相似推荐”。“研究内容相近”找研究问题或方法相关论文；种子标题明确涉及大语言模型时，候选也须有模型线索。“摘要结构参考”要求原始摘要共同出现至少两类可观察的写作线索，可以展开原始摘要对照。“同刊相似论文”核对完整刊名并筛选相关条目。
4. 查看推荐依据、来源和术语出现篇数，再点击“在本页查看与分析”。推荐不是空卡片，返回记录会先保存为可读取的论文 ID。
5. 暂无摘要不代表论文没有摘要。可通过校园网或授权馆藏取得 PDF 后，在详情中导入全文；本版不代登录馆藏，也不生成假摘要填空。

## 推荐的范围

每次查询 OpenAlex 和 Crossref，各取最多 30 篇候选，跨源去重并排除当前论文，最终最多展示 12 篇（界面默认 6 篇）。使用已有搜索容量限制，来源失败或限流独立展示。正文生成模型不参与推荐，避免为了查看相似论文额外调用付费大模型。

DeepSeek、Qwen、GPT 的频次各自计算，按候选标题和摘要中出现该词的论文篇数统计，不是词语重复次数。同刊模式的分母仅为本次同刊候选，不冒充全刊发文趋势。写作结构标签是摘要措辞线索，不是全文目录分析，也不评价论文质量。

测试使用隔离的临时数据库，未把测试论文写入用户知识库，也未读取或调用用户模型 Key。

- 离线覆盖中英互查、通用词误匹配、领域与任务区分、跨源去重、源失败、摘要缺失、同刊分母、取消与重试、推荐详情及分析 ID 一致性。

三次推荐的 18 条返回记录均通过真实详情接口读取。所有推荐来源请求在最终这轮均成功；测试中也确实出现过失败，修复过程保留如下：

- 初测主题推荐 33.64 秒后两源超时。确认同步证书加载阻塞事件循环后，学术源改为复用受限后台证书加载机制，保留证书验证、环境代理与取消控制，没有通过关闭 TLS 校验提速。
- 初测一条摘要结构种子返回 404。确认同 DOI 在不同数据源返回不同 ID，而旧搜索先发布结果再批量保存，可能回滚。搜索和推荐现在共用身份复用逻辑，先提交有效本地 ID 再发布结果；保存失败明确报错。
- 界面实测 50 篇结果中可筛出 41 篇有摘要、9 篇暂无摘要；数学不等式与多段 HTML/JATS 摘要另有回归，防止清理标记时截断原文。
- 后续界面测试发现后台补查期刊指标也会阻塞详情读取。本版补查同样使用后台证书加载，8 秒总预算覆盖排队和网络请求；缓存命中立即返回，超时保留原有指标。没有以关闭证书校验的方式规避网络问题。

有限词表仍不等于语义理解，罕见术语、缩写、多义词和源元数据缺失仍可能影响召回与排序。本次验证的是这些具体业务场景，不是所有学科或所有模型功能的再次验收。
