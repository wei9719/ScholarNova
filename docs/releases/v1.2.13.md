# ScholarNova v1.2.13 — 期刊发现与原文伴读

这一版把“找论文、看期刊、取得全文、按页读懂、留下自己的笔记”接成连续流程，继续使用现有知识库，不另建重复的学习模块。

## 新增能力

- 搜索结果中主动点击“查询相关期刊”，核对期刊类型、ISSN、来源和本次候选范围，继续查看该刊相关论文。
- 期刊指标分别保留名称、年份和来源。OpenAlex 开放指标不冒充影响因子；正式 JIF 只取本机带年份的授权导入数据。作者指南从可靠主页核对，不编造地址。
- 论文详情可打开绑定论文的授权浏览窗口。校园通道使用独立直连会话，公共通道沿用系统网络；用户自行登录，识别或下载 PDF，核对文件和论文身份后确认导入。
- “原文伴读”进入智能体中的指定论文工作区，提供翻译选段、解释段落、解释公式、读图表、补基础与练习、整理写作样例、阅读拓展七类任务。
- 选择 2–5 篇已有本地全文的论文，比较有来源的写作样例；核对后整理为现有技能卡草稿，确认保存才入库。
- 保留页码与文件版本，替换全文后清理相应旧分析，处理切换论文的晚返回；限制授权窗口与下载，关闭主窗口后可以正常重新启动。

## 使用前先了解

导入 PDF 只在本地保存与解析，不自动调用云模型。点击伴读或分析任务后，才将本次需要的选段、页面或有界材料发送给配置的服务。公式与读图任务需要明确配置实际支持图像的视觉模型；扫描件目前没有自动 OCR。

多篇写作对照只抽取每篇首、第二和末页，每页最多 1,600 字符，不代表完整通读或全刊写作规范。原文相关解释、教学建议和自己的记录分别保留；阅读推荐、练习建议与个人进度不是掌握程度认证。

学校订阅、验证码、统一身份认证和网络条件仍由用户按学校要求准备。内嵌页面不兼容时，使用外部浏览器合法下载，再手动导入；不代登录、不绕过权限、不后台批量抓取 Google Scholar。
