## 4. 验收中遇到的情况与发布待办

1. **1.2.16 尚未公开发布。** 当天 GitHub 的 `releases/latest` 仍指向 1.2.14。安装界面中的版本源码下载、版本代码链接已经按 1.2.16 生成，但尚无相应公开 Release／标签；因此这两项不能算作下载可用。公开发版前须准备对应源码、标签及附件，并逐项验证链接。本轮不擅自创建 Release，也不把 README 下载改到未发布地址。
2. **验收工具出现过访问限制。** 备份副本的 Electron 存储读取首次因受限执行环境退出，使用允许的正常执行重试后成功，没有关闭应用安全机制。一次受限环境健康查询超时，正常本机查询 `/api/v1/health/live` 返回 `ok` 和 1.2.16。失败尝试不计通过。
3. **长笔记的自动化文字读取曾卡住。** 恢复自动化连接后，原生截图确认笔记已正常打开，随后可返回原文并显示 PDF；未重复创建笔记、清除存储或将工具卡顿当作数据丢失。
