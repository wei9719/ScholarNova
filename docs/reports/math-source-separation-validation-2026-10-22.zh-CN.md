# 数学原文与教学补充分离：1.2.16 候选回放

日期：2026-10-22。实现提交：`71cf710`。本轮只处理“解释公式”的来源分栏、展示和保存，不把一次测试外推为所有数学回答正确。测试使用已有授权本地 PDF 和现有 API 凭据；配置、完整回答和资料备份留在私有测试目录，不进入 GitHub。

## 为什么不能只加提示词

此前只检查 `source_notes` 是否带本页来源编号。模型即使把常见位置编码知识写成作者定义，附上 `[P4]` 也能通过这个检查。新实现不再保留模型自由撰写的数学原文说明，而是由服务端重建原文栏：只接受本次实际发送文字节选中的连续摘录，合并排版空白，不执行 NFKC、不替换上标、数学字母或词间边界。

最多接收 6 条、每条 12–800 字符的候选摘录。查找范围为实际选段，未选时为当前页前 8,000 字符；不是整篇论文。匹配成功的摘录与服务端页码才进入原文栏，解释、常识、译释和视觉公式转录均属于教学补充或未核实草稿。模型放错栏的内容也会移出，并去掉可能被误认作原文证据的页号标记。过程不增加第二次模型调用。

这一步核对的是“文字是否出现”，不是“数学解释是否被原文支持”。未匹配可能由提取、扫描或节选范围导致，不能说整篇论文没有定义。其他伴读模式不受这项数学专用规则影响。

## 真实论文与模型请求

直接通过实际 HTTP 伴读接口获取文档、文件版本、页图并发起请求，没有用固定回答替代模型。人工对照了两张完整原页：

- GATGPT，PDF 第 4 页，位置编码公式与图注意力模块。文件 SHA256：`791ce65e663f2618be2d556592d9cb390f32b14ce43d1caf217357b821aa8b2e`。
- STD-PLM，PDF 第 8 页，4.1 数据集段与 Table 2。文件 SHA256：`031731734478997c577cf7218174e89966e090f28165734a1395cc530929e42f`。

硅基流动的 Qwen3-VL-30B-A3B-Instruct 四次伴读均未完成。随后只读查询确认型号仍在列表，但最短生成探测返回 HTTP 402、错误码 30001、账户余额不足。未返回用量的请求记为用量未知，不能记为免费，也没有把生成失败算作分栏通过。

改用已有 GLM 凭据，仅在隔离服务内覆盖视觉任务，没有更改正式模型配置。[GLM-4.6V-Flash 官方文档](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash)说明支持图像输入；它的实际测试仍不理想：一题限流，两题把偶奇嵌入维度误说成偶奇位置，其中一题还错误改写 cos 的指数；另一次返回不合规 JSON，未给出三指标算例。3 次有用量响应合计 11,908 Token。这些失败全部保留，来源隔离成立不等于教学内容合格。

随后用同平台 `glm-4.6v` 完整型号重新测试，均为实际模型调用：

这四次合计 15,675 Token，均正常完成且未附练习。原文栏逐项重新匹配实际发送的节选，没有夹带模型解释；教学不再借页号假装已核实。Token 是服务商返回的统计，不是结算金额。

GATGPT 的 PDF 文字抽取把位置编码分母压成了 `100002i/dmodel`。某条成功匹配的摘录保留了这个压平文本，它不是完整公式排版认证。实际幂次仍需查看原页；不能因文字匹配通过就声称公式已自动验证。

## 界面、保存与重新打开

在 5191 隔离工作区实际进入 GATGPT 第 4 页，选择“解释公式”、提交问题，再调用 `glm-4.6v`，返回 3,696 Token。界面分别展示“原文摘录（本页文字匹配）”“教学补充与未核实解读（非作者明文）”及独立匹配说明。该次回答正确区分位置与维度，但未完整写出所问指数表达式，因此来源分栏通过，回答完整性仍有不足，不将其说成全部教学要求已满足。

将回答核对后保存到“数学来源核对 2026-10-22”独立测试分类。编辑器的数学章节原文栏为空，两个来源标题、匹配详情、页码和文件版本保存在 AI 建议，个人测试记录另存。服务端只读核验新笔记已落盘，未用 AI 内容补填论文原文。测试笔记位于隔离资料副本，不是正式资料中的科研成果。

## 边界

原文栏的自由数学解释混入路径已改为本地强制分离；这不代表模型不会答错、不会漏答，也不把中文教学译释认证为作者明文。视觉转录、符号推导、整篇论文的定义覆盖仍需人工核对。硅基流动恢复余额前，不能宣称本轮 Qwen 成功复测；也不发布未经原生业务核验的新 macOS 安装包。
