# 1.2.13 期刊发现与原文伴读验收

验证日期：2026 年 10 月 16 日。使用隔离的测试资料库，不修改使用者的真实论文、笔记或对话。模型凭据只在内存中读取，不放入源码、截图或报告。

## 实际业务链路

在界面搜索 `traffic flow imputation`，快速检索约 7.3 秒返回 50 篇候选，来源包括 Crossref 与 OpenAlex。结果中出现 2026 年条目；这证明本次查询能够取得近期记录，不代表数据库已经完整收录当日论文。

主动查询期刊后，实际核对到 IEEE Transactions on Intelligent Transportation Systems、Transportation Research Part C 等期刊的 Source ID 和 ISSN，再查询该刊的相关论文。补充服务有界等待，未完成的部分保留提示；会议和书系不冒充已核验期刊。正式 JIF 未授权导入时不显示虚构数值。

导入两篇公开论文进行测试：GRIN（arXiv:2108.00298v3）和 DCRNN（arXiv:1707.01926v3）。两份文件通过身份预览、保存、解析与本地全文列表检查，分别建立页码与文件哈希。它们属于会议论文，写作对照不概括为同一期刊要求。

以上是单次小样本，不是性能承诺、计费清单或事实正确率。来源格式合格不等于结论全部正确。人工抽查发现小视觉模型会对图边含义过度推断，已加强“当前页无明文则不补造机制”的任务约束；公式、数值和推导仍要对照原页。

初轮 Qwen 文本回答有遗漏方括号来源的情况，系统将其降为未核验草稿。强化实际来源标签和 JSON 示例后，上表各文字任务复测通过，没有自动补造引用，也没有增加模型自修循环。当前 GLM 视觉配置返回过 429；较大千问视觉模型出现过超时，失败仍显示真实状态。

测试还定位到 SiliconFlow 明确 Instruct 模型不接受 `enable_thinking` 参数：同一图片去掉该参数后请求成功。现已同步修复实际调用、连接测试与任务探测；普通文字模型原策略不变。图像任务一次请求，不回退文字冒充读图。

## 界面与保存

实际操作完成选段翻译、填写个人理解、打开现有阅读笔记编辑器及保存。论文材料、AI 建议和个人记录分别进入对应栏目，不另建知识库。错误选段返回 422，旧文件版本返回 409，未触发模型。

## 本版范围

学校订阅与统一身份认证必须由使用者实际授权。没有用本次公开论文测试冒充校园登录验收；内嵌不兼容时保留外部下载、手动导入。私有内网地址不在内嵌窗口支持范围。应用的校园直连会话不会修改系统 VPN，也无法解除系统级隧道。

扫描 PDF 暂无自动 OCR。多篇写作对照只取首、第二和末页的有界样例；官方投稿要求仍要回期刊网站核对。Windows 本地升级、macOS 原生构建和公开发行结果以安装检查及同版本 Release 实际附件为准，不由源码版本号推定。
