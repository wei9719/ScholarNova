# ScholarNova 1.2.13：从找期刊到读懂论文

更新日期：2026 年 10 月 16 日。本文是当前源码的使用案例与人工检查清单，不把页面入口、模拟测试或 Windows 构建等同于真实学校订阅验收。公开安装包、操作系统与版本以 [Release 附件](https://github.com/wei9719/ScholarNova/releases/latest)为准；本轮不宣称新 macOS 包已完成构建。

这一版延续“搜索 → 阅读 → 笔记 → 知识库 → 问答与路线”，补上相关期刊、独立授权全文窗口、原文伴读和多篇写作样例。已有[完整研究案例 Word 手册](../guides/ScholarNova完整研究案例使用手册.docx)对应 1.2.12，可继续学习基础流程；新增入口看[在线手册第 12 节](../USER_MANUAL.zh-CN.md#12-1213期刊发现授权全文和原文伴读)。

## 一、准备一个真实研究问题

案例：**METR-LA 交通速度观测发生随机缺失或连续缺失时，怎样修复，并怎样公平比较方法？**

这是学习任务，不声称已经发现新方法或完成实验。METR-LA 的典型观测是道路速度，不要直接写成车辆流量。建立研究分类“交通速度缺失修复”，准备自己的模型配置和有权使用的论文。

| 准备项 | 作用 |
| --- | --- |
| 科研问答智能体模型 | 解释段落、补基础、写作观察与阅读拓展 |
| 翻译模型 | 指定段落翻译，保留术语、变量与语气 |
| 图表/架构分析视觉模型 | 指定页的公式与图表解释；需要服务实际支持图像输入 |
| 至少一篇可阅读的授权 PDF | 按页伴读的材料来源；打开伴读不会自动下载或调用模型 |
| 另一篇可读全文 | 后续做 2–5 篇写作样例对照；不能用无全文条目凑数 |

先“测试连接”再“保存配置”，也检查任务配置和备用模型。测试成功不代表该模型同时支持文字、图像与出图。云端任务只在你明确点击后调用，但停止等待不保证上游未接收或不会计费。

## 二、先找文章，再看期刊

1. 在搜索页输入“交通速度 缺失数据 修复”，选择近期年份并完成搜索。再用 `traffic speed imputation` 补充查询；需要经典基线时改“全部年份”。
2. 核对论文研究的是缺失观测修复还是未来预测。相关分数是排序线索，不是研究任务相同的证明。
3. 点击“查询相关期刊”。它由用户主动发起，初次论文搜索不会等候该查询。
4. 检查“期刊已核对”与“发表源待核验”。后者可能是会议、书系或预印本，不直接当成投稿期刊；已核对项保留 OpenAlex Source ID 与 ISSN。
5. 点击“查看该刊相关论文”继续查当前关键词，选择文章打开详情。查询失败时仍保留当前命中文献供阅读。
6. 从已知期刊主页查作者指南，核对目标文章类型、摘要、篇幅、图表与参考文献要求。没有权威指南地址时不自动生成 URL。

候选命中数只来自当前结果，补充发现数只来自此次 OpenAlex 返回样本，不是全刊发文占比。指标分开显示名称、来源和年度；OpenAlex 开放指标不等于正式影响因子。正式 JIF 需要本地有权使用的数据及明确年份。

如需导入 JIF，到“设置 → 期刊分区、影响因子与开放指标”，点击“导入分区 / JIF CSV/JSON”。最小 CSV 如下，**数据只作格式演示，不对应真实期刊**：

```csv
Journal,JIF,JIF Year,Source
目标期刊完整名称,5.4,2025,本人授权数据来源
```

可增加 `ISSN` 列；冲突时不应用该项。缺少年度的 JIF 不作为可用正式指标。成功查询可使用十分钟内缓存，界面会标记；投稿前仍需再次核对期刊官方信息和指标年度。

## 三、通过正确通道取得全文

普通搜索使用已配置学术 API。搜索页的校园门户和 Google Scholar 是用户主动浏览入口；Google Scholar 不在后台批量抓取。它们尚未绑定论文，不会把浏览中任何 PDF 自动导入到随意一篇文章。

要导入当前文章，请先在论文详情中选定它，再从绑定入口进入：

| 路径 | 具体操作 |
| --- | --- |
| 公共开放来源 | 打开当前论文的公共授权浏览入口，使用系统网络；识别 PDF 或点击网页下载按钮 |
| 校园与机构 | 点击“机构授权获取”，在独立直连会话中自己完成学校/数据库认证，找到该论文全文 |
| 不兼容网页 | 切外部浏览器，按合法权限下载；回论文详情或伴读导入文件 |

授权窗口上方应显示绑定论文标题。识别 PDF 后选择对应文件；下载完成，在确认框核对文件名、来源、首页身份提示和绑定论文。身份提示只是核对线索，错误或无法判断时取消，不要覆盖现有全文。

确认导入后只在本地保存与解析，不自动发送云模型。回论文详情看全文/索引状态，再明确点击 AI 分析或“原文伴读”。替换 PDF 会改变文件版本，原来的页码定位需要复核。

学校要求的校园网络、VPN 或 WebVPN 仍由用户准备。校园窗口的“直连”只是应用内会话不使用系统代理，不能创造订阅权限，也不能保证绕过系统级网络隧道。外部浏览器 Cookie 不会自动导入应用。具体数据库登录、动态下载或内网地址不兼容时，保留手动下载与导入路径。单文件上限 50 MB，下载存在超时限制。

## 四、不要让 AI 代替自己读一整篇

从论文详情点击“原文伴读”，进入智能体页面 `/assistant?paper=论文ID`。指定页可查看文字和原页图像；PDF 页序可能与论文印刷页码不同。选择或粘贴同页原文后再提问，服务器核对选段与文件版本。

按以下顺序走一次：

1. **翻译选段**：选中一段方法描述，让模型保留符号、缩写和语气。比较原文，不把“可能改善”译成“证明改善”。
2. **解释段落**：问“这段的研究对象、输入、输出和假设分别是什么？”缺少其他页信息时，转到对应页面继续读，不要求它猜完整方法。
3. **解释公式**：配置视觉模型后，指定该页公式，要求说明符号与维度，指出哪些推导是论文内容、哪些是教学补充。
4. **读图表**：核对坐标、单位、图例和样本。看不清的数字不作为真实结果；不要从示意图编造实验提升。
5. **补基础与练习**：例如询问“这个状态转移为什么使用马尔科夫假设？给一个两状态例子，再让我手算两步”。先把自己的解法写进个人记录。
6. **整理写作样例**：选摘要或引言段落，问其论述功能和衔接方式，提炼可填写骨架，不复制句子替换几个词。
7. **阅读拓展**：要求列出应补基础、可检索关键词以及不同方法的比较方向，再通过真实检索选择后续论文。

文字任务使用选段或该页有界文字，不一次塞入整篇论文；选段上限 6,000 字符，未选段时当前页上下文最多 8,000 字符，问题最多 2,000 字符。公式/图表任务使用指定页图像与可提取文字，不读取其他页。扫描件目前无自动 OCR，图像解释需要已配置且确实支持图像的视觉模型。

回答区区分原文相关解释、教学补充与练习，并保留页码、文件版本、材料范围和模型信息。它们仍是待核对的建议，不是掌握证明；“已经读过”和“能够自己解释与计算”是两件事。

## 五、把有用内容沉淀到同一个知识库

先选择研究分类，写自己的疑问、计算与实践记录，再使用“整理为阅读笔记”“整理为基础知识卡”或“整理为技能 / 写作卡”。应用打开现有编辑器，人工核对之后保存才入库。原文材料、AI 建议和个人记录分开存放，不新增一套重复知识库。

本篇伴读只临时保留最近 12 次回答，不是自动归档。离开前保存重要内容；替换 PDF 会清理未保存的伴读选段与回答，个人记录仍需在编辑器确认保存。保存后的卡片可在知识库按分类和类型查找，再供普通智能体的分类问答使用。

## 六、比较多篇，形成自己的写作清单

1. 在“整理写作样例”任务下展开“多篇写作样例对照（2–5 篇）”。选择有本地全文的样本，优先相同文章类型，想比较期刊风格时再限定相同期刊。
2. 问一个具体结构问题，例如“比较样本怎样从研究问题过渡到方法和结果；分别列出可填写的功能提纲”。
3. 检查覆盖范围：**每篇只抽取首、第二及末页，每页最多 1,600 字符**，不是完整通读；页面不一定包含全部摘要、图表或结论。
4. 检查每条来源中的文章、PDF 页码、文件版本和摘录，按来源入口回原页。扫描件或文字不足会提示，不通过猜测补足。
5. 区分“官方作者指南”“样本观察”“我自己的模板”，点击“核对后整理为技能 / 写作卡”，确认分类和内容后保存。

跨刊或缺少刊名时，结果只是样本比较，不能写成某期刊统一标准。样本共同采用某种摘要写法，也不代表审稿人要求所有文章照做。填写模板时使用自己的研究内容、真实结果与引用，不复用原句或让模型伪造实验。

## 七、人工检查清单

| 场景 | 应当看到的结果 |
| --- | --- |
| 首次文献搜索 | 论文搜索不等待未点击的期刊查询；主动查询后标明期刊核验和样本范围 |
| 期刊服务不可用 | 明示未完成；当前发表源聚合保留，待核验项不冒充确认期刊 |
| 授权窗口未绑定论文 | 提示从论文详情进入，不擅自选择目标论文 |
| 错文件、登录页或取消确认 | 不作为正确全文自动导入；已有材料不能被一次误点静默覆盖 |
| 授权导入成功 | 本地解析与状态刷新；不自动云调用；进入伴读后可看页码和版本 |
| A 下载时切换到 B | A 导入后只使 A 的旧分析失效，不把 A 状态写到 B |
| 选择另一页或替换 PDF | 原文定位、选段与文件版本对应；旧版本请求拒绝或提示重载 |
| 扫描件、无视觉配置 | 明示无 OCR 或缺少视觉模型，不假称已读取公式/图像 |
| 伴读模型失败 | 显示未完成和可核对材料，原文仍可阅读；不把失败草稿保存成知识 |
| 写作样本少于 2 篇或多于 5 篇 | 不执行对照，要求调整样本；无全文不能凑数 |
| 草稿与长期保存 | 返回回答、打开编辑器、保存成功是不同步骤；保存后能在知识库找回 |
| 主窗口关闭后再次启动 | 应用能够正常重新启动，不被遗留授权窗口占住主界面 |

这里是使用与检查标准，不替代该版本的实际测试结果。真实 API、安装检查、学校数据库和操作系统验收应分别记录，不能从一个成功案例推断其他场景全部完成。
