# ScholarNova v1.2.14 — 原文检索与真实场景修复

本版围绕真实阅读与知识积累流程修复，不增加重复入口。

- 指定论文、页码和表号先定位原文。长论文或后导入论文不再挤掉旧文献的全部检索片段；没有指定页表时明确提示，不用别的论文补答案。
- 问答界面显示本次来源是 PDF 原文还是知识笔记，并列出实际 PDF 页码。“引用标记检查通过”只说明编号和标记对应，不代表事实已核验。
- 段落翻译给直接译文，不再用摘要转述代替；无选段时可翻译本页有界文字。图例与公式变量提示更明确，数学教学仍需人工逐式核算。
- 写作对照优先定位摘要和结论，每篇最多 4800 字符；缺失章节与截断会提示。九章阅读笔记按栏目正文线索选材，减少重复摘要挤占实验和公式内容。
- Zotero 重复导入按目标集合内 DOI / 题名去重，避免重复点击增加条目。已验证元数据写入与回读，PDF 附件同步仍未支持。
- 修正搜索同义词误交集、问句噪声和零相关候选排序；使用既有有界细化，结果不足时不凑数，显示匹配范围与来源状态。
- AI 润色先保存原文，再提供可编辑草稿；用户明确采用后才更新，不直接覆盖事实与个人记录。
- 商汤图像任务新增已实测的 U1.5 Lite；路线导出可带确定性 SVG 架构，JSON 不混入正文。HTML 兼容 `.doc` 不等于原生 Word 文件。

实际测试结果与未通过项见[完整实测记录](../reports/v1.2.14-functional-validation.zh-CN.md)。图像服务、学术源限流和机构订阅受外部服务与授权影响，不把接口成功当成内容质量保证。

升级前退出旧应用并备份个人数据目录。模型配置、论文和笔记位于安装目录之外；源码更新不会自动替换安装包。Windows / Intel Mac / Apple Silicon Mac 的可用安装包、对应源码及校验值，以本版本 Release 的实际附件为准。当前未配置 Windows 商业签名或 Apple 公证。
