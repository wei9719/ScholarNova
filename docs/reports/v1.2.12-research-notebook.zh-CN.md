# v1.2.12：文献时效与研究学习笔记验收

日期：2026-10-13。此次是“检索—阅读—复现记录—知识与技能积累”的第一阶段，不是自动完成论文或执行实验的软件。

## 本次交付范围

1. 检索时间条件下推到 Crossref、OpenAlex、Semantic Scholar 与 arXiv，保存日级发表日期；没有日级日期的记录按年份近似处理。界面支持全部年份、今年至今、近三年至今和自定义年份，显示检索时刻及索引、缓存限制。
2. 搜索页选择笔记研究分类，论文详情直接新建或继续该分类下的阅读笔记。无须先调用分析；空分类使用“未分类”。只有明确保存的笔记持久化，临时搜索仍按已有会话规则清理。
3. 复用知识库现有卡片结构，不增加重复数据库或菜单。笔记包含思路、复现、资源联系、公式、前置知识、写作伪代码、图表、双语、排版九章；各章区分论文材料、AI 建议与个人记录。
4. 一次只生成一章建议，使用设置中的分析模型与本地已读片段。草稿显示来源快照、覆盖范围和实际返回用量，确认追加与保存是两步独立操作。源码、数据网址与公开邮箱为本地提取，不调用模型、不自动访问链接。
5. 知识库按阅读笔记、基础知识和技能卡筛选，可把已有笔记内容提炼为可编辑卡片，支持 Markdown 导出。新建普通条目默认保留原文；阅读笔记禁止自动压缩。
6. 新增更新时间防覆盖检查、章节切换/分类切换迟到结果保护、类型往返内容保留、失败草稿禁止加入；资料进入现有检索索引时保留归属标签，个人想法不会被直接标作论文原文。

## 界面验收

在生产前端构建和独立后端上完成：打开阅读笔记、切换章节、本地提取资源、确认追加、保存、再次打开核对来源快照、提炼基础知识卡、保存并按类型筛选。首次界面检查发现元信息占满首屏，已将标题/类型/分类收紧排布，来源信息可折叠，沿用现有主题。

重点自动验收还包括：同一论文不同研究分类不串写，A→B→A 的旧请求不能覆盖新请求，分类读取失败不假装创建成功，长公式原样保存，409 冲突保留编辑内容，草稿失败不冒充本地零调用，未确认草稿不进入笔记。

## 使用前应理解的边界

- “检索至今”指各源已收录记录，非当日全部论文。每个来源仍返回有限候选；默认相关性排序不是按新旧抢占首位，发表时间不代表学术创新性。
- 草稿按上下文预算选择已缓存片段，不额外下载全文、读图或验证数学证明。来源编号合法不等于归纳一定正确，缺少材料不等于作者没有公开。
- 实验章保存方案、命令和实际日志，不运行代码；资料提炼不代表用户已掌握知识。绘图、伪代码、双语与 LaTeX/Word 章节是建议与记录，既有研究路线制图功能仍从原入口使用。
- 本期不新增原生 DOCX/PDF 排版器、LaTeX 编译器、公式渲染器或自动文献全文授权登录。云端辅助会发送所选材料片段，请确认资料可发给所选模型服务商。
- 当前提供更新冲突检测和关闭编辑器时的未保存提醒，不是浏览器崩溃后的草稿恢复系统。重要修改及时保存或导出。
