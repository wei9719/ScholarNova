# 1.2.14 全功能实测与修复记录

日期：2026-10-17。研究场景为道路交通时序数据缺失修复，使用已导入的 GATGPT、STD-PLM 等论文与独立测试分类。测试调用用户本机已配置的 GLM、Qwen 与 Qwen-VL；未把密钥、用户数据库或论文 PDF 上传到仓库。

## 一、如何判断完成

分别检查请求是否成功、模型是否真实调用、所需材料是否进入上下文、引用能否定位、事实是否符合原文，以及用户任务是否完成。HTTP 200、`model_completed` 或引用编号对应，都不能单独证明任务成功。

先在已安装 1.2.13 中复现，再通过一致性数据库备份和全文副本，在独立的 1.2.14 本地服务中复验；不将测试副本回写个人数据库。真实场景只新增专用测试资料，不清理或搬移用户原来的文献。

本轮累计记录 148 条 API 检查，49 条检查含模型调用或尝试证据；其中 28 条返回显式 `model_attempts`，共 31 条尝试记录。返回并被记录的 Token 为 117315。这些口径不等于服务商总请求数或账单，图像服务等内部调用不一定完整返回用量。

## 四、保留的未通过项

1. 数学视觉任务：新提示改善位置索引与嵌入维度区分，但模型仍生成过错误教学公式，最终视觉数学复验约 37.1 秒超时，不能用旧回答冒充成功。固定提示“未经过符号计算验证”，进一步限制未验算的公式和代入例子。它是辅助阅读，不是数学证明器。
2. 复杂检索与主题推荐：核心文献召回与排序已经改善，但 GSF-LLM 的未来插补展望仍可能被判为直接匹配，跨域综述也可能进入部分相关。Semantic Scholar 429 在显式四源测试中形成约 42.67 秒长尾，不能宣称限流已消除。
3. 多轮与跨论文事实：追问已能进入正确论文实验页，但模型仍把 MSE 误述为绝对误差；长比较复验约 11.97 秒、3989 Token，7 项核心事实正确，另补了一句缺少原文支持的预测划分。正确引用编号不代表额外事实成立，以上回答保留为部分通过。
4. Zotero PDF：当前同步路径仅验证元数据；3 篇测试文献没有通过该路径传入 PDF 附件。`pdf_imported=false` 与提示必须保留。
5. 图像与时效：旧 `sensenova-u1-fast` 404 已由 Lite 的成功实测形成可用替代，但不是旧模型已恢复；生成图仍有英文标签、水印和小字可读性问题。研究推荐规划曾建议只重点看 2024–2025，精确页答案有重复事实句，仍需改善日期上下文和回答组织。
