# 1.2.9：检索与分析可靠性

日期：2026-10-03。该版本是源码与本地 Windows 测试候选，不是已发布安装包。已安装版本不会随 GitHub 提交自动升级。

## 本轮解决什么

| 用户操作 | 原问题 | 本轮行为 |
| --- | --- | --- |
| 输入普通关键词查论文 | 简单查询也可能先等模型，增加时间与调用 | 默认自动判断，短主题直接生成规则计划；用户可手选快速检索或 AI 规划 |
| 同一关键词换策略再查 | 最近搜索加载后输入框可能仍为空 | 输入框跟随实际路由查询变化，同词、同模式或换模式均可重新提交 |
| 阅读较长论文 | 获得 PDF 容易被理解为模型看完全部内容 | 显示章节摘录、正文和图表文字截断，以及实际提供的图表页数 |
| 一边生成路线，一边管理资料 | 慢模型占用数据库连接；旧结果可能覆盖新修改 | 提前释放读连接，使用材料快照；保存时检查路线是否仍是原版本 |
| 多个任务生成图片 | 共用图片文件名，可能出现旧路线引用新图片 | 每次运行使用独立图片名；只在校验成功后原子保存 |
| 测试图像模型 | 返回一个链接便可能被当作成功 | 真正下载并解码 PNG；404、网页错误、截断、超大或压缩响应不再算成功 |
| 遇到设置或检索参数错误 | 对象型错误直接渲染可能导致白屏 | 提取有限的错误文字，不展示请求输入、配置和原始异常对象 |

## 检索模式与时间、费用

- **自动规划**：按短主题、比较、排除、问句等明确规则判断。它是可解释的启发式，不是保证正确的语义分类器；判断不合适时可手选模式。
- **快速检索**：不调用查询规划模型。论文分析、翻译、可选嵌入等其它任务仍可能按配置调用模型，因此不称为“所有功能免费”。
- **AI 规划**：一次模型请求，约 20 秒模型等待预算、21 秒外围规划预算；不再叠加 SDK 重试和备用模型。失败、空计划或无效来源回到规则计划。已尝试但未返回用量的请求仍可能计费。

检索总时间还包含排队、学术源、去重与排序，不能用规划预算代替端到端耗时。取消会向客户端调用传播，但不能保证服务商已停止计算或计费。

## 全文和并发边界

正文、章节、图注和表格文字合计取最多 48,000 字符，覆盖说明另计。这是字符预算，不是精确 Token 预算，不保证每个供应商都能接受相同长度。解析出章节时使用章节摘录；图注最多前 20 个，表格最多前 8 张、每张前 12 行，并受总预算约束。图像页仍为有界选择，不能声称看过整篇所有图片。

知识分析、推荐、路线生成和 PDF 下载前释放读取连接。路线最后保存采用条件更新，检查标题、描述、关联知识、状态与原分析是否变化；被删除、修改或另一个任务先保存时拒绝旧结果。等待模型期间依据的是启动时快照，不是不断变化的实时知识库。

生成接口响应限制为 2 MB，下载 PNG 限制为 20 MB、单边最多 8,192 像素、总像素最多 2,000 万。请求不跟随重定向，图片地址要求公共 HTTPS，HTTP 压缩响应在读取前拒绝。生成和下载分别设置 300 秒、120 秒网络阶段预算；这些不包括全部解析及排队时间。API 凭据不转发给图片下载地址。

## 你可以这样验收

1. 在搜索页输入“联邦学习”，选择自动规划。确认展示规则直检策略、真实源名称与耗时，而不是一直停在模型规划。
2. 不改关键词，选择 AI 规划再提交。确认产生新的检索任务；再次提交同词也有响应。该步骤会调用已配置模型，可能收费。
3. 离开后回到搜索页，点击本窗口的最近搜索词。确认输入框出现该词，可换模式再次查询；旧分析不应自动恢复为新检索结果。
4. 导入自己有权使用的长 PDF 并分析。确认材料覆盖提示说明节选或截断；抽查结论能否回到原文，不把格式正确等同于事实正确。真实模型分析可能收费。
5. 从知识库选择资料，填写研究目标，生成分析并显式保存路线。等待期间切换资料列表，应仍可读取。该步骤的模型能力须另做真实验收。
6. 在一个任务生成路线期间修改路线描述；较早任务返回后应提示无法保存旧结果，保留最新描述。不要为了测试这一竞争情况盲目多次付费出图；已有离线并发用例覆盖此行为。
7. 生成图片成功时查看真实图片。下载失败或返回网页时应明确失败，旧图仍在；如果服务商已生成但下载失败，重试可能再次计费。
8. 设置中输入错误参数并测试，搜索中模拟错误请求，确认显示文字提示且页面仍可操作。关闭候选版后再打开，检查正常启动。
